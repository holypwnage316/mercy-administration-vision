# Mercy Administration Vision

A simple discussion site for ministry opportunities at Mercy PCA and Tithely's
possible role in supporting them.

The page frames hospitality, guest follow-up, communication, church database,
messaging, and worship planning improvements as a shared ministry pathway:
helping people move from visiting, to belonging, to serving, to growing. Each
area can link a ministry need back to a relevant Tithely service or product page.

Open `index.html` in a browser to view the site locally.

## Netlify

This is a static site with no build step. In Netlify, import the repository and
use the repository root as the publish directory.
